Quick update!

Hi! I just wanted to write something because, well, it's been a while! (sorry for ghosting) (no pun intended, lol)

I've been a bit occupied lately (hence the ghosting)... But! I have managed to do a few things!

I've,

  • Decided to use a SSG (static site generator) to be able to write markdown rather than raw HTML for writing blog posts (the SSG converts markdown into HTML) (writing raw HTML just got too cumbersome for me, and an SSG felt like a good middle ground before creating an actual server application)
  • Learned 11ty - the SSG 🙂 (it was both smooth and not smooth to learn, haha - it felt as though they try to make it "easy/simple", but in doing so, they leave out key things for learning)
  • Ported my raw HTML blog to 11ty
  • Configured GitHub Pages to host an 11ty-generated SSG via "GitHub Actions" (which are actually very cool)
  • Researched and discovered StackEdit for writing blog posts (ie, creating/editing markdown files in my GitHub repo 🙂) (in fact, I'm writing this post in StackEdit right now 👀)

Lots of goodies discovered! Lots of adventures! 🧙‍♂️

I plan to do posts about all of these things, but for now I just wanted to do this small update!
